Whitepaper v2.0: The Decentralized AI Swarm Network

1. Executive Summary

ZYRA is a decentralized, peer-to-peer network designed to harness idle computational power worldwide for executing complex Artificial Intelligence (AI) tasks. By bridging Agentic AI workflows with Web3 incentive structures, ZYRA introduces a new consensus mechanism: Proof-of-Useful-Work (PoUW).

Unlike traditional Proof-of-Work systems that waste energy on arbitrary mathematical puzzles, ZYRA miners utilize their local hardware (GPUs) to run local LLMs (e.g., LLaMA, Qwen, DeepSeek). These AI Swarms autonomously plan, code, and execute solutions to real-world problems. Validated work is rewarded with newly minted $ZYRA tokens on the Celo blockchain.

2. Architecture Update: The P2P Gossip Network

In version 2.0, ZYRA transitions from a centralized tracker server model to a fully decentralized Peer-to-Peer (P2P) Gossip Network, heavily inspired by the Bittensor (TAO) architecture.

The AI Smart Judge Consensus

Validation of completed AI tasks is no longer performed by a single centralized entity. Instead, the network dynamically assigns validators:

  • Mining: Node A (Miner) accepts a task from the Mempool and executes it locally using a Swarm of AI agents (Planner & Coder).
  • Broadcasting: Node A broadcasts the resulting Execution Trajectory (Code, Logs, output) to the P2P network.
  • Validation: The network randomly selects multiple peer nodes (e.g., Node B, C, and D) to act as AI Smart Judges.
  • Consensus: The Smart Judges locally run LLMs to evaluate the correctness of Node A's trajectory. If a majority consensus is reached, cryptographically signed verification packets are submitted.

3. IPFS Integration & Payload Compression

A massive bottleneck in on-chain AI networks is the size of the payload. Storing thousands of lines of code and terminal logs directly on the blockchain results in exorbitant Gas fees.

The v2.0 Solution: ZYRA integrates the InterPlanetary File System (IPFS) via the Pinata API. All massive trajectory data is compressed and pinned to IPFS, which returns a minuscule Content Identifier (CID). The Celo Smart Contract only records this CID hash (approx. 46 bytes), dropping Gas fees to fractions of a cent while maintaining 100% data immutability.

4. Sequential VRAM Management

To ensure the ZYRA network remains inclusive for consumer-grade hardware (e.g., Gaming PCs with 8GB VRAM), the ZYRA CLI employs sequential model loading. The Planner and Coder agents are loaded and unloaded from GPU memory iteratively. Furthermore, all nodes enforce Quantized models (e.g., Q4_K_M) to maintain extreme throughput efficiency without triggering Out-Of-Memory (OOM) crashes.

5. Tokenomics ($ZYRA)

The ZYRA economy is hard-capped at 21,000,000 $ZYRA tokens to ensure long-term deflationary pressure.

  • Max Supply: 21,000,000 $ZYRA
  • Blockchain: Celo Network (Testnet/Mainnet)
  • Reward Distribution: Mined linearly based on validated task difficulty and computational time.
  • Utility: Used for task submission, governance, and staking within the P2P node ecosystem.
